# core:orbit test fixtures — provenance

Every file here is external reference data. None of it was produced by SatRide's own code: a test
that checks an implementation against its own output proves nothing.

| File | Source | Licence | What it validates |
|---|---|---|---|
| `SGP4-VER.TLE` | AIAA 2006-6753 verification set, as distributed with the Vallado reference implementation (via [python-sgp4](https://github.com/brandon-rhodes/python-sgp4)) | Public domain | The 30-ish TLEs the SGP4/SDP4 test suite propagates, including deliberately pathological orbits |
| `tcppver.out` | Golden output of the same AIAA verification set | Public domain | Expected TEME position/velocity per satellite per time step — the authoritative SGP4 correctness check |
| `orbit_reference.json` | Generated by `gen_reference.py` using **Skyfield 1.54** (+ python-sgp4) and **pygeomag** | Data derived from public-domain models | Coordinate chain (TEME→ECEF→topocentric), sub-satellite points, pass search, Doppler and WMM declination |
| `WMM2025.COF` | NOAA/NCEI World Magnetic Model 2025 coefficients (via the `pygeomag` package) | Public domain (US Government work) | The declination model itself; epoch 2025.0, valid 2025–2030 |
| `gen_reference.py` | Kept alongside the data it produced | — | Reproducibility: re-run it to regenerate `orbit_reference.json` |

## On independence

SGP4 propagation is validated against `tcppver.out`, which is the authoritative published output
for that algorithm — the strongest check available.

`orbit_reference.json` comes from Skyfield, which also uses a Vallado-derived SGP4. That makes it
a *weak* independent check of propagation but a *strong* one for everything downstream — the
TEME→ITRF rotation, topocentric az/el/range, range-rate, sub-satellite points and pass event
search are all separate code paths in Skyfield, written by different people from ours.

Small expected differences: we apply the GMST rotation without polar motion (a few tenths of an
arcsecond, ~1e-4 degrees) and use a low-precision solar position for the eclipse test. Test
tolerances are set accordingly and documented at each assertion.

## Regenerating

```bash
python3 -m venv venv && ./venv/bin/pip install skyfield pygeomag
./venv/bin/python gen_reference.py
```

The ISS TLE is pinned inside the script (epoch 2026-08-01) so regeneration is deterministic.
Do not swap it for a live TLE — the expected values here are tied to that specific element set.
